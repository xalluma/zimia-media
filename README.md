# zimia-media

Imágenes y vídeos de las publicaciones de Instagram de [@zimiapets](https://www.instagram.com/zimiapets/).

Instagram solo publica archivos que pueda descargar de una dirección pública, así que viven aquí.
Una carpeta por pieza del calendario (`ZIM-002/01.jpg`, `02.jpg`…). Los sube
`publicador/subir_media.py` del calendario; no se editan a mano.
